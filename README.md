# BorrowMate Founder Capstone

BorrowMate is a frontend MVP for a neighbourhood equipment sharing marketplace. It helps users browse local tools and equipment, filter listings, inspect item details, and send a simple booking request.

## What is included

- Home and browse screen
- Search
- Category filter
- Price filter
- Distance filter
- Item detail screen
- Two-step booking flow
- Authentication screen
- Responsive design
- Typed mock data
- Founder response
- Decision log
- AI usage log

## What was deliberately not built

I did not build fake urgency counters, forced login before browsing, maps, messaging, referral codes, or offline mode. These were deferred or reshaped because the sprint needed a focused MVP and some requests would harm user trust.
